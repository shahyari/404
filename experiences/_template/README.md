# Experience template

1. Copy this folder to `experiences/your-experience-name/`. Use lowercase, with words separated by hyphens. The folder name becomes the URL.
2. Build your 404 page in `index.html`, `style.css` and `script.js`. Add any other files you need and load them with relative paths.
3. Fill in `meta.json`. Every field is described in [docs/METADATA.md](../../docs/METADATA.md).
4. Run `npm run dev` and open http://localhost:5173/your-experience-name/.
5. Run `npm run check`, then open a pull request.

What your experience can and can't do inside the sandbox: [docs/PERMISSIONS.md](../../docs/PERMISSIONS.md).
Full guide and guidelines: [CONTRIBUTING.md](../../CONTRIBUTING.md).

You can delete this README from your copy.
